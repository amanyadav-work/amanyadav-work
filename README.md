If it can be built, scaled, or optimized, I’m probably already tinkering with it.

I like building things that don’t just run—they **scale**, handle edge cases, and survive real-world use. From RBAC systems to data ingestion pipelines, I enjoy tackling the parts of a project that make it actually production-ready.
